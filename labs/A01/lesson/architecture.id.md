# Prinsip Arsitektur Broken Access Control

Kebijakan kontrol akses (Access Control Policy) bertugas memastikan bahwa setiap pengguna tidak dapat melakukan tindakan di luar batas hak yang telah ditentukan.

Ketika lapisan arsitektur ini gagal, dampaknya mencakup pengungkapan informasi sensitif tanpa izin, manipulasi data kritis, hingga pengambilalihan kontrol sistem secara menyeluruh.

### Verifikasi Arsitektur Zero-Recompile
Materi dan instruksi ini disajikan secara dinamis pada aplikasi ZITERA_LAB langsung dari repositori laboratorium tanpa perlu mengompilasi ulang binary aplikasi utama.
