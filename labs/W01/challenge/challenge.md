# Misi CTF: Cross-Site Request Forgery (CSRF) & Token Defense (W01)

Selamat datang di tantangan praktikum **W01**! Pada tantangan ini, kemampuan analisis dan pengujian keamanan Anda akan diuji secara langsung.

### [TARGET] Sasaran Misi (Objective):
Analisis target aplikasi **NexusPay Wire Portal** yang berjalan pada port `8021`. Buktikan adanya kelemahan keamanan pada modul ini dengan memicu kondisi kerentanan dan dapatkan string flag resmi dengan format:
`ZITERA{csrf_token_defense_bypassed_2026}`

### Petunjuk Teknis:
1. Pastikan lab dalam keadaan berjalan (Status: RUNNING).
2. Akses target via peramban web pada `http://127.0.0.1:8021/`.
3. Lakukan pengujian form interaktif atau gunakan tombol trigger exploit yang disediakan.
4. Salin flag yang muncul dan masukkan ke form verifikasi di bawah ini untuk mengonfirmasi kelulusan Anda!
