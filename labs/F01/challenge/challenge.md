# Misi CTF: Dasar Protokol HTTP & Web Architecture (F01)

Selamat datang di tantangan praktikum **F01**! Pada tantangan ini, kemampuan analisis dan pengujian keamanan Anda akan diuji secara langsung.

### [TARGET] Sasaran Misi (Objective):
Analisis target aplikasi **HTTP Protocol Inspector** yang berjalan pada port `8026`. Buktikan adanya kelemahan keamanan pada modul ini dengan memicu kondisi kerentanan dan dapatkan string flag resmi dengan format:
`ZITERA{http_protocol_header_mastery_2026}`

### Petunjuk Teknis:
1. Pastikan lab dalam keadaan berjalan (Status: RUNNING).
2. Akses target via peramban web pada `http://127.0.0.1:8026/`.
3. Lakukan pengujian form interaktif atau gunakan tombol trigger exploit yang disediakan.
4. Salin flag yang muncul dan masukkan ke form verifikasi di bawah ini untuk mengonfirmasi kelulusan Anda!
