# A08: Software or Data Integrity Failures (Kegagalan Integritas Data & Software)

Software and Data Integrity Failures berfokus pada asumsi kode dan infrastruktur yang tidak melindungi integritas data dari modifikasi ilegal.

Hal ini terjadi saat aplikasi mengonsumsi plugin, pustaka, pembaruan otomatis (*auto-updates*), atau data serialisasi (*untrusted deserialization*) dari sumber yang tidak diverifikasi keaslian tanda tangannya.
