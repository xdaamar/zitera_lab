# Misi CTF: Dasar Query Database & Pemisahan Data/Perintah (F05)

Selamat datang di tantangan praktikum **F05**! Pada tantangan ini, kemampuan analisis dan pengujian keamanan Anda akan diuji secara langsung.

### [TARGET] Sasaran Misi (Objective):
Analisis target aplikasi **SQL Query Compiler Visualizer** yang berjalan pada port `8030`. Buktikan adanya kelemahan keamanan pada modul ini dengan memicu kondisi kerentanan dan dapatkan string flag resmi dengan format:
`ZITERA{sql_syntax_boundary_isolation_2026}`

### Petunjuk Teknis:
1. Pastikan lab dalam keadaan berjalan (Status: RUNNING).
2. Akses target via peramban web pada `http://127.0.0.1:8030/`.
3. Lakukan pengujian form interaktif atau gunakan tombol trigger exploit yang disediakan.
4. Salin flag yang muncul dan masukkan ke form verifikasi di bawah ini untuk mengonfirmasi kelulusan Anda!
